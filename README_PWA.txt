ADC Studio PWA Offline v2.1

Arquitetura:
- Cada PC/telemóvel/tablet guarda os seus projetos localmente e funciona independente dos restantes.
- Não existe servidor central nem sincronização automática.
- iPhone/iPad podem transferir projetos manualmente através de Ficheiros/iCloud Drive usando .adcproj.
- Cópias completas permitem proteger todos os dados do dispositivo.

Instalação:
1. Publicar esta pasta por HTTPS (ex.: GitHub Pages).
2. Abrir o endereço no Safari/Chrome/Edge.
3. iPhone/iPad: Partilhar > Adicionar ao Ecrã Principal.
4. PC/Android: usar a opção Instalar aplicação quando disponível.
5. Depois da primeira carga completa, a app funciona offline.
